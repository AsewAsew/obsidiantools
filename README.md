# Obsidian Tools
Just as the name suggests, adding an Obsidian tier between Diamond and Netherite. They're all crafted using new Refined Obsidian Ingots. All tools and armor are properly enchantable, with an enchantability slightly higher than Netherite.

## Items & Blocks
Obsidian Shards: Obtained by smelting Obsidian. Also has a rare chance to drop while breaking Obsidian. Think of them as a "nugget".

Refined Obsidian Ingot: Crafted using nine Obsidian Shards.

Refined Obsidian Block: Crafted using nine Refined Obsidian Ingots. Has standard Obsidian features plus is immune to Withers and the Ender Dragon.

## Tools
Mining Speed slightly faster than Netherite (10 vs. Netherite's 9).

Damage Amount/Speed same as Diamond.

## Armor
Same Armor Value and Toughness as Diamond with Netherite's knockback resistance.

## Misc
Refined Obsidian Blocks and Crying Obsidian used in Nether Portal frames.

Can be upgraded into Netherite just like Diamond.
